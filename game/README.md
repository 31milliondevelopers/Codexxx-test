# Крестики-нолики 4x4 (Tkinter)

Простое desktop-приложение для двух игроков на одном компьютере.

## Можно ли запускать без установленного Python?
Коротко: **исходник (`main.py`) — нет**, нужен Python + Tkinter.

Но можно собрать **Windows `.exe`**, и тогда на компьютере игрока Python не требуется.

## Что есть в приложении
- поле 4x4;
- поочерёдные ходы X и O;
- запрет хода в занятую клетку;
- победа при 4 символах подряд (строка, столбец, диагональ);
- ничья при полном поле без победителя;
- отображение текущего хода и результата;
- кнопка **«Начать заново»**.

## Обычный запуск (из исходника)

```bash
cd game
python3 main.py
```

## Сборка Windows `.exe`
> Выполняется на **Windows**.

1. Откройте `cmd` в папке `game`.
2. Запустите:
   ```bat
   build_windows_exe.bat
   ```
3. Готовый файл появится здесь:
   ```
   game\dist\TicTacToe4x4.exe
   ```

## Если не запускается
Если появляется ошибка `tk.TclError`, обычно это значит, что:
- не установлен Tkinter/Tk;
- или нет доступа к графическому окружению (например, запуск в headless-среде без дисплея).
