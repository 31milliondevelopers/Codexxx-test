# Крестики-нолики 4x4 для Windows 7 (без сторонних установок)

Игра переписана как **desktop-приложение HTA** на встроенном в Windows 7 языке VBScript.

## Запуск без установок
### Вариант 1 (самый простой, уже готово)
- Двойной клик по `TicTacToe4x4.hta`.
- Ничего устанавливать не нужно.

### Вариант 2 (если нужен именно `.exe`)
- В папке `game` запустите `make_exe_win7_builtin.bat`.
- Скрипт использует только штатный Windows 7 инструмент `IExpress` (без Python и без сторонних программ).
- На выходе получите `TicTacToe4x4.exe` в этой же папке.

## Что реализовано
- поле 4x4;
- два игрока на одном компьютере;
- ходы по очереди: X и O;
- запрет хода в занятую клетку;
- победа при 4 символах подряд (горизонталь, вертикаль, диагональ);
- ничья при полном поле без победителя;
- отображение текущего хода и результата;
- кнопка «Начать заново».
